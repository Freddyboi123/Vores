# Vores Øjeblik

## Vision

As someone that grew up in the 2000s, and got to experience the prime of social medias,
it anoys me greatly to see what many of these platforms have grown into today. 

What once was a save space to share moments and funny stories  
has grown into a place filled with advertisement, politics, hate, and disagreement 

This is why i chose to make this project, a more personal social media for Danish people, 
that is filled with stuff much nearer to home instead of distant distractions and clickbaits.


Example:
> You will be able to share posts with friends and family.
> 
> You will be able to like, dislike, and comment on other posts.
> 
> It will be possible to change privacy settings to make a public feed of content and a private one just for your friends.
>
> You can add people as a friend to easily stay in touch with their content

# Architecture

## System Overview

This project is segmented into multiple different layers.

- Controller layer (REST endpoints)
- Service layer (business logic)
- DAO layer (database access)
- Config layer (database settings and security details)
- DevTool layer (personal tools i set up)
- Entity layer (all the POJO I will work)
- API layer (handles all external API traffic)

- Java

- JPA / Hibernate
